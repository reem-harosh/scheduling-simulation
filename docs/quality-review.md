## ממצאים לפי חשיבות

- **P0:** לא נמצאו תקלות חוסמות במודל שנבדק.
- **P1, תוקן:** הפרדת קלט התרחיש מהמנוע. נוספו `scenario.json`, בדיקת תקינות הקלט ומספרי ישויות וכשירויות הנגזרים מהנתונים בממשק. נשמרו ערכי ברירת המחדל המקוריים.
- **P1, תוקן:** שמירת ניסויים והשוואת כללי שיבוץ. ההשוואה מוגבלת לאותו תרחיש, אופק, הליכה, שונות ורשימת זרעים בפועל. זמן השהייה מוצג ראשון, ואחריו סיום כולל ואיחור; סדרות עם הרצות חלקיות אינן מדורגות.
- **P2, תוקן:** הובהר ש־SPT משתמש בזמנים שנדגמו מראש וידועים בעת השיבוץ.
- **P2, תוקן:** עודכנו הוראות GitHub ונוספו בדיקות קבועות לתנועת עובדים, מעברי מצבים והשוואות.
- **P2, תוקן בבדיקת סיום ממוקדת:** שדה `due` חסר התקבל בבדיקת הקלט אך גרם לשגיאה בהמשך. כעת הוא מנורמל ל־`null` / `None`, ונוספה בדיקת רגרסיה.
- **P2, נותר:** בדיקת שימושיות חזותית בדפדפן ובטלפון. לא בוצעו אינטראקציות בדפדפן או בדיקת רינדור במהלך הביקורת; ההערכה החזותית מבוססת על HTML/CSS/Canvas ועל בדיקות פונקציות המצב והתנועה. אין כאן אישור לנגישות או לשימושיות מלאה.

## עדויות

בבדיקה הראשונית הסוכן הריץ שבע בדיקות מנוע ועוד 168 בדיקות נקודתיות למצב עובדים ועבודות. לאחר השיפורים עברו תשע בדיקות Python ובדיקות Node קבועות. לאחר תיקון שדה היעד החסר עברו עשר בדיקות Python ובדיקות Node.
